## Project 1 — Linux System Health Checker

Built a Bash automation script that monitors system health inside an Ubuntu Docker container.

### Key Features

- System information and hostname
- CPU and memory monitoring
- Disk usage monitoring
- System uptime
- Top five processes by CPU usage
- Automated warning when disk usage exceeds 80%

### What I Learnt

- Navigating and managing files using the terminal.
- Running Linux environments using Docker.
- Using Docker bind mounts.
- Writing Bash scripts and conditional statements.
- Processing command output using pipes, awk, grep and tr.
- Managing Linux file permissions.
- Troubleshooting errors independently.
